# 🇨🇦 Canadian Science Museum Navigator

An iOS SwiftUI application that allows visitors to browse and search artifacts from a Canadian science museum. This project was created for the MWD3A iOS Development course and is based on the concepts learned in TheMet API tutorial.

---

## Features

- 🔍 Search museum artifacts
- 🏛️ View Canadian museum collections
- 📄 Artifact detail screen
- 🧭 Navigation using NavigationStack
- 📦 JSON data using Codable
- 🎨 SwiftUI user interface
- 📱 Responsive iPhone layout

---

## Technologies Used

- Swift
- SwiftUI
- Xcode
- Codable
- ObservableObject
- JSON
